## 1. 一句话

**把玩家放进五个真实的两难里，先让他做出选择，再告诉他这个选择在数学上意味着什么。**

---

## 2. 为什么是《三体》

《三体》几乎是一本用小说写成的博弈论教材：

- **黑暗战役**是一个标准的囚徒困境，而且是一个「有限次重复」的版本——逆向归纳会让合作从最后一轮开始崩塌；
- **黑暗森林威慑**是胆小鬼博弈与边缘政策的教科书案例，核心问题是「如何让对方相信你真的会按下」；
- **猜疑链**本质上是没有共同知识的信号博弈，而**技术爆炸**给这个博弈加上了时间贴现；
- **面壁计划**是一个信息不对称的零和博弈：你的最优策略不是「想出最好的计划」，而是「让对手无法预测」；
- **宇宙归零**是一个阈值公共品博弈：所有人都知道该归还质量，但每个人都想少还一点——差一点，就全都没有；
- 最后，**「不要回答」**是一个一次性博弈，它提醒你：博弈论能算出均衡，却算不出你想要什么。

这六个场景刚好覆盖了初学者最该先掌握的六个模型，而且它们共享同一个世界观，玩家不需要在每章重新理解一次「我是谁、我为什么在这里」。

## 3. 设计原则

### 3.1 先体验，后解释

每一章都分成两段：**先玩，后读**。

- 玩的时候只给必要的信息：局面、选项、收益。不给概念名，不给公式。
- 玩完之后才翻开「博弈论手记」，用玩家刚刚做出的真实选择来解释模型。

这样做的原因很简单：如果先讲定义，玩家会把它当成一道有标准答案的题；先做选择，玩家才会对「我明明想合作，为什么还是点了开火」这件事产生疑问。疑问比定义更能让人记住。

### 3.2 每个机制都必须「长」自一个模型

不做「答题闯关」，也不做「数值对撞」。每一章的核心操作，必须本身就是那个博弈：

- 第 1 章的选择是同时决策的收益矩阵；
- 第 2 章的选择是威慑度与意志之间的资源分配；
- 第 3 章的选择是后验概率下的行动；
- 第 4 章的选择是混合策略中的一次抽样；
- 第 5 章的选择是阈值公共品里的一次贡献。

如果删掉这个概念，这一章就玩不起来了——这是判断机制是否成立的标准。

### 3.3 失败也有教学价值

游戏没有「Game Over 重来」的惩罚，只有不同的结局。被背叛、威慑失败、判断错文明、被破壁，都会进入对应的手记。**输掉的那一局，往往比赢的那一局更能说明问题。**

### 3.4 不隐藏规则，只隐藏信息

收益矩阵、阈值、先验概率都对玩家可见。真正的不确定性来自对手的选择、隐藏的文明类型、以及你自己会不会被看穿。

这是刻意的：初学者的难点不是「算不出收益」，而是「不知道怎么在不确定下做决定」。把规则摊开，才能把注意力集中在后者。

### 3.5 不假设玩家读过原著

《三体》的背景是气氛，不是门槛。为了让没看过原著的玩家也能进入局面，游戏做了四层解释：

1. **标题页的「新手指南」入口**：直接打开世界观速览；
2. **随时可打开的手册**：世界观 / 25 个概念 / 操作，三个标签页；每个概念含定义、公式（如适用）、例子与常见误解；
3. **正文里的行内词条**：带虚线的词点开就是 10 秒解释，还可以跳到手册看全文；
4. **每章开头的可折叠背景注**：只讲这一章真正需要知道的那几件事。

原则是：**背景解释必须在玩家需要它的那一刻出现**，而不是要求他先读完一本设定集。

## 4. 信息架构与节奏

```
标题
 └─ 序章（约 1 分钟）
     ├─ 第一章 黑暗战役（4 回合 + 结局 + 手记）
     ├─ 第二章 执剑人（8 回合 + 结局 + 手记）
     ├─ 第三章 猜疑链（5 次接触 + 结局 + 手记）
     ├─ 第四章 面壁者（5 回合 + 结局 + 手记）
     ├─ 第五章 归零（6 回合 + 结局 + 手记）
     ├─ 尾声 不要回答（1 次选择）
     └─ 实验报告（数据 + 人格 + 概念索引 + 推荐阅读）
```

- 每章开头有一页「档案式」的简报：章节号、标题、题记、情境、规则、开始按钮。
- 游戏界面固定为「左场景 / 右决策」的双栏结构，移动端改为决策优先的单栏。
- 每章结束先给结局卡，再给手记；手记由「结论 → 模型 → 公式 → 概念卡 → 下一章预告」组成。
- 顶部 HUD 用五个进度点标记章节位置，右侧标出本章的核心概念。
- 标题页提供「章节选择」，允许重玩任意一章——这是二次学习的关键：先看手记，再回去用另一种策略验证。
- 右上角的「?」在任何界面都能打开手册；手册是覆盖层（modal），不会丢失当前章节的状态。

总时长约 25 分钟；手记部分可以跳读，不影响通关。

## 5. 章节设计

### 5.1 第一章 · 黑暗战役

**情境**：末日之战后，五艘人类战舰逃离太阳系，资源只够一艘船的人活下去。你是蓝色空间号的舰长，对手是终极规律号。

**模型**：囚徒困境（同时决策，4 轮）

**收益矩阵**（每轮生存点数）：

| | 对方沉默 | 对方开火 |
|---|---|---|
| **你沉默** | +3 , +3 | −5 , +5 |
| **你开火** | +5 , −5 | −2 , −2 |

满足 T > R > P > S：开火是双方的**占优策略**，(开火, 开火) 是唯一的**纳什均衡**，但 (沉默, 沉默) 才是**帕累托最优**。

**对手 AI**：

1. 第 1 轮沉默（试探）；
2. 第 2–3 轮：如果你曾经开火，就永远开火（冷酷触发）；否则继续沉默；
3. 第 4 轮无条件开火。

第 4 轮的背叛是关键设计。它让玩家亲身体验「逆向归纳」：明明前三轮都合作了，为什么最后一轮还是打起来了？手记会给出答案——因为在最后一轮，开火仍然占优；而一旦双方都知道最后一轮会开火，倒数第二轮的合作就没有意义，如此一路倒推。

AI 并不是「完全理性」的。如果它从第一轮就开火，玩家只会觉得「这游戏好难」；让它先合作三轮、最后一轮翻脸，玩家才会感到被背叛，而这个情绪正是理解有限重复博弈的入口。

**结局分支**：

| 条件 | 结局 |
|---|---|
| 第 1 轮先发制人 | 先发制人 · 唯一幸存者 |
| 全程沉默 | 罕见的合作 · 例外 |
| 总分 ≤ −4 | 先眨眼的人 · 阵亡 |
| 其他 | 带着弹孔继续航行 · 幸存 |

**教学点**：囚徒困境、占优策略、纳什均衡、帕累托最优、逆向归纳、重复博弈、一报还一报。

**叙事层**：四轮各有一套独立战报——同样是「双方沉默」，第一轮是交换物资，第二轮是「谢谢」，第三轮是深空号消失后的互相靠近；开火、被背叛、同归于尽也各有轮次特写。开局补了「深海状态」，结局补了次声波氢弹与「我们活下来了」的日志。

### 5.2 第二章 · 执剑人

**情境**：地下五千米，引力波发射控制室。你握着开关，与三体舰队对峙八年。

**模型**：胆小鬼博弈 + 边缘政策 + 可信承诺

**核心循环**：每年选择一个姿态，然后三体根据「威慑度 D」与当年的「试探阈值」决定收敛还是试探。

| 行动 | 威慑度 | 意志 | 其他 |
|---|---|---|---|
| 沉默对峙 | ±0 | −6 | |
| 公开警告 | +9 | −13 | |
| 展示疯狂 | +22 | −21 | 冷却 1 年；意志 < 25 时不可用 |
| 让步 | −12 | +19 | 评估后舰队额外推进 1 |

- 初始：D = 55，S = 100，推进 T = 0。
- 阈值：`42 + (年份 − 1) × 6`，第八年为 84。
- 评估：`D ≥ 阈值` → 收敛（T −1）；否则 → 试探（T +1，D −4）。
- 失败：意志 ≤ 0（崩溃）、推进 ≥ 8（入侵）、D < 25（被看穿）、第八年评估失败。
- 胜利：第八年评估成功。

**设计意图**：把「可信承诺」变成一种会被消耗的资源。

- 展示疯狂能大幅提高威慑度，但消耗意志；意志见底就再也硬不起来。
- 让步能恢复意志，但会降低威慑度，并让舰队前进——**示弱是有代价的，而硬撑也是有代价的**。
- 阈值随年份上升，意味着你必须不断加码；这正是边缘政策的动力学。

**平衡验证**：对 4 种行动、8 个回合的全部合法序列做穷举（约 3.4 万条），胜率约 **42.7%**。其中：

- 全程「公开警告」会在第八年意志归零而崩溃（D 已到 100，但人先垮了）；
- 「警告 / 沉默」交替可以赢，最终 D ≈ 91、S ≈ 24；
- 前期沉默、最后三年连续强硬也可以赢，但推进会到 3 左右。

没有唯一解，但每种解都要付出不同的代价——这是这一章想要的平衡。

**手记**：胆小鬼博弈的 2×2 收益表、可信承诺（把方向盘扔出窗外）、边缘政策、疯子理论、罗辑与程心的对比、威慑度的贝叶斯解释。

**叙事层**：八年，每一年有一个独立的「局势」事件（智子来访、舰队越过奥尔特云、联合国讨论继任者……）；每个行动有 6–7 条按使用次数轮换的台词；智子的回应有 7 条「收敛」与 5 条「试探」，并会因威慑度过高、舰队推进、意志崩溃触发专属台词；同一行动连续三次会触发一次性的「重复」特写。所有台词只出现一次或轮换，不会每次都给你同一句话。

### 5.3 第三章 · 猜疑链

**情境**：你是深空监听站的分析员，五次接触未知文明。每次只能看到信号，看不到对方的类型。

**模型**：贝叶斯信号博弈

**每次接触的信息**：

- 先验 P(善意)；
- 一个观测（收到信号 / 静默）；
- 似然 P(观测 | 善意) 与 P(观测 | 猎手)。

**五次接触的数值**：

| # | 星域 | 先验 | 观测 | P(观测\|善意) | P(观测\|猎手) | 后验 |
|---|---|---|---|---|---|---|
| 1 | 中立星域 | 50% | 质数序列 | 80% | 40% | 67% |
| 2 | 中立星域 | 50% | 静默 | 25% | 65% | 28% |
| 3 | 猎场 7A | 30% | 童谣 | 70% | 55% | 35% |
| 4 | 摇篮 3F | 75% | 坐标交换 | 90% | 50% | 84% |
| 5 | 镜像 | 50% | 通用问候协议 | 85% | 85% | 50% |

第 3 次是**基础比率**的教学点：信号看起来很友好，但先验只有 30%，后验仍然只有 35%。

第 5 次是**混同均衡**的教学点：善意与猎手发送同一个信号的概率相同，因此信号不携带任何信息，后验等于先验。这是整章的高潮——「它发出的，正是你会发出的信号」。

**行动与收益**：

| 行动 | 善意文明 | 猎手文明 |
|---|---|---|
| 接触 | +2 知识，暴露 +8 | 安全 −1，暴露 +30 |
| 静默 | 无 | 无 |
| 清除 | 知识 −1，道德 −1，暴露 +10 | 安全 +1，知识 +1，暴露 +12 |

- 每次接触前可以选择「延长监听」：消耗 6 点暴露，再观测一次（按当前后验抽样）。
- 安全 ≤ 0 → 被猎杀；暴露 ≥ 100 → 坐标暴露；撑过五次 → 监听继续。
- 游戏会实时显示贝叶斯演算：先验、两个似然、后验，让玩家看见「信念如何随证据移动」。

**设计意图**：让「猜疑链」从一个抽象名词变成一次次具体的计算。玩家会发现自己不是在判断「对方是好是坏」，而是在判断「在这个先验下，这个信号能把我推向哪里」。

**叙事层**：五次接触各有独立的接触/清除/静默文本——质数序列、静默、童谣、坐标交换、通用问候，同一个动作在不同文明身上会发生不同的事。第三次接触后插入一条新闻：4.2 光年外的一颗恒星被光粒摧毁，有人在你之前回答了那个信号。

### 5.4 第四章 · 面壁者

**情境**：你是第四位面壁者，要在三种计划中选择；破壁人会预测你的选择并采取对策。五轮对决。

**模型**：零和博弈 + 混合策略

**收益矩阵**（你的得分）：

| | 封锁 | 干扰 | 诱导 |
|---|---|---|---|
| **掩体** | −3 | +2 | +1 |
| **黑域** | +1 | −3 | +2 |
| **光速** | +2 | +1 | −3 |

每一行、每一列的和都是 0，这是一个零和博弈。任何纯策略都会被针对；唯一的纳什均衡是三种计划各 1/3，博弈值为 0。

**破壁人 AI**：

1. 用带衰减的计数维护一个关于你下一步的概率分布；
2. 你选了某个计划，该计划的权重 +2.4，其余权重乘以 0.86（下限 0.55）；
3. 按这个分布计算每一列的期望收益，选择让你收益最低的一列（82%），其余情况随机。

游戏在每一轮**决策之前**就把这个预测分布显示给玩家，并换算成一个「可预测性」百分比：

```
可预测性 = (最大概率 − 1/3) / (2/3) × 100%
```

均匀分布时是 0%，完全被锁定在某一手时是 100%。这个数字会随着你的选择模式上升——它逼你面对一个事实：**你以为的随机，其实有很强的模式。**

**设计意图**：玩家可以尝试「针对破壁人的预测反着选」，这会形成一层层的心理博弈（level-k reasoning）。但只要你形成新的固定模式，预测就会跟上。真正的解法是随机化——游戏给了两次「面壁者的骰子」，但只有两次，因为完全外包给骰子也就不好玩了。

**叙事层**：三种计划 × 三种对策有九种结果文本；每轮开头有局势事件——第三位面壁者的计划被公开、第二位被破壁、第一位死亡，最后只剩你。连续三次选同一个计划，破壁人会当面说：「你总是选同一个。这不是策略，是习惯。」

**手记**：零和博弈、混合策略、极小极大定理、人类为什么不会随机、石头剪刀布。

### 5.5 第五章 · 归零

**情境**：宇宙正在加速膨胀。归零者向全宇宙广播：请归还你们占有的质量。五个文明，六轮，临界值 34。你是「回声」文明的领袖。

**模型**：阈值公共品博弈 + 保证博弈 + 协调博弈

**规则**：

- 5 个文明（你 + 4 个 AI），6 轮，每轮各自归还 0 / 1 / 2 个单位的质量；
- 你保留的质量 = 12 − 你归还的总量；
- 六轮结束后，累计归还 ≥ 34 → 宇宙坍缩、重生；否则宇宙永远膨胀；
- 理论上限 60。如果每个文明每轮只归还 1，总量是 30，刚好不够。

**四个邻居的策略**：

| 文明 | 策略 | 它在教什么 |
|---|---|---|
| 归零者 | 每轮归还 2 | 有人必须先多付一点，公共品才可能被提供 |
| 守望者 | 总量跟上进度就归还 2，落后就只归还 1 | 条件合作者会失去信心 |
| 商人 | 达标前归还 1；最后一轮差额大时归还 2；达标后停止 | 理性计算者的边界 |
| 孩子 | 复制你上一轮的选择 | 你的行为是一个公共信号 |

**叙事层**：六轮各有一段宇宙广播——归零者的第一次广播、歌者的歌声、一个拒绝归还的年轻文明、膨胀速率、田园时代的录音、最后一次「还差最后一点」。结局里补了「田园时代」的回响。

**设计意图**：把「公地悲剧」变成一个可以看见的账本。

- 每一轮的总量、进度、你的保留质量都摊在桌面上。你知道该还，也知道少还一点不会立刻出事。
- 孩子是这一章的情感核心：它不计算，它学你。你保留全部，它就也保留；你归还，它就跟上。这让玩家第一次直观地看到「重复博弈里的声誉」是怎么运作的。
- 守望者的策略让「落后」产生连锁反应：你少还，总量落后，它也跟着少还，缺口变大。公地悲剧不是一次性发生的，它是一轮一轮滑坡的。

**平衡验证**（固定策略模拟）：

| 策略 | 你的贡献 | 最终总量 | 结果 |
|---|---|---|---|
| 每轮保留全部 | 0 | 28 | 失败 · 永死 |
| 每轮归还一半 | 6 | 41 | 成功 · 刚好够 |
| 每轮归还全部 | 12 | 51 | 成功 · 归零者 |
| 前松后紧（0,0,0,2,2,2） | 6 | 39 | 成功 |
| 精打细算（1,1,1,1,0,0） | 4 | 38 | 成功 · 搭便车的人 |

全员只归还 1 是不够的（30 < 34），是归零者每轮多还的 1 个单位补上了缺口。这个设计想让玩家意识到：**好的均衡往往需要一个愿意多付的人。**

**结局分支**：

- 成功 + 贡献 ≥ 10 → 归零者
- 成功 + 贡献 ≤ 4 → 搭便车的人
- 成功 + 其他 → 刚好够
- 失败 + 贡献 ≥ 10 → 无人应答（安全网，正常游玩很难触发）
- 失败 + 其他 → 永死

**手记**：公地悲剧、阈值公共品、保证博弈、多重均衡、焦点、搭便车；并用一张表公开四个邻居的策略——机制透明，判断才可学。

### 5.6 尾声 · 不要回答

**情境**：你是三体世界的监听员 1379，收到来自太阳系的问候。

**模型**：一次性博弈，没有下一轮、没有声誉、没有重复。

三个选择：

1. 回复「不要回答」——牺牲自己，警告对方；
2. 上报坐标——履行职责，让自己的文明活下来；
3. 关闭接收器——不作为。

这里**故意不做收益计算**。手记只说明一件事：博弈论可以告诉你哪个选择是「均衡」，但不能告诉你你想要什么。这是整部游戏的价值论落点，也是对「理性」的一次反问。

## 7. 视觉设计

**基调**：深空黑（#04060b）+ 冷青（#6fd9ff）+ 警戒红（#ff5d5d）+ 沙金（#f2c879）。

- **背景**：Canvas 星野，约 200–340 颗星，带视差漂移与偶发流星；叠加噪点与径向渐变，避免大面积纯黑显得廉价。
- **字体**：叙事用宋体 / Noto Serif SC，界面用无衬线，数据用等宽。三种字体的对比承担了「文学 / 操作 / 仪器」三种语气。
- **HUD**：细线、小号等宽字、四角括号、扫描线，营造「仪器面板」的感觉，而不是「游戏 UI」。
- **一章一景**：五章各有一个可拖拽旋转的 3D 全息线框：第 1 章战术球体、第 2 章威慑控制台、第 3 章信号球、第 4 章计划金字塔、第 5 章质量环。场景不是装饰，它承载状态：球体上会少一艘船，威慑台的地球与舰队随威慑度 / 推进变化，信号球的光束与 P(善意) 环随后验变化，金字塔的光束对应破壁人的预测与对策，质量环的缺口对应还差多少质量。
- **3D 全息**：场景由自写的 Canvas 线框渲染器绘制，没有 Three.js、没有 WebGL、没有依赖。它只做点、线、节点和透视投影，却足够画出球体经纬线、威慑台、信号球、四面体光束和环面粒子。相机支持偏航 / 俯仰 / 距离；拖动旋转、滚轮缩放、双击复位，方向键也能转；`prefers-reduced-motion` 下停止自动旋转。
- **标题页**：只保留标题、两行引文、一组竖排按钮和一行来源；新玩家看到「开始游戏 / 新手指南」，有存档时看到「继续 / 章节选择 / 手册 / 重新开始」，重新开始是独立按钮并二次确认。用一条地平线弧光收束画面，页脚只写「改编自刘慈欣《三体》世界观 · 非官方同人」。
- **动效**：克制的淡入与位移；只有「按下开关」「展示疯狂」这类关键动作才有强反馈。尊重 `prefers-reduced-motion`。
- **手册**：不是一个新页面，而是一个覆盖层。它保持游戏的视觉语言（细线、等宽小字、暗底），但用更大的行距和更松的留白，让玩家知道「现在可以慢下来读」。

## 8. 声音设计

全部由 Web Audio 实时合成，没有音频文件：

- **底噪**：48 / 72.5 / 96.2 / 193 Hz 四个振荡器经过 360 Hz 低通滤波，音量很低，像一间机房的电流声；加一个 193 Hz 的弱谐波，是为了让笔记本小喇叭也能听见；
- **点击**：620 Hz 三角波，40 ms；
- **确认**：392 → 587 Hz 两音上行；
- **警报**：110 Hz 锯齿波下滑，用于背叛、试探、失败；
- **按下开关**：60 Hz 正弦 + 90 Hz 三角波，1.4 秒的长衰减。

**总线结构**：音乐（环境底噪）与音效（点击、警报、关键动作）各走一条独立的 Gain 总线，再汇入主输出。这样「音乐 20%、音效 80%」是真正分开的，而不是把同一路声音整体调小。主输出增益 0.9，默认音乐 85%、音效 100%——比初版整体响约 5–8 dB，同时保留不削波的余量。

**声音面板**：右下角的「声音」按钮打开一个轻量弹层，提供两条 0–100 的滑杆、一键静音、实时数值；所有改动立即生效，并写入 `localStorage`（`darkforest.audio`）。打开手册时，声音按钮会被禁用，避免两个覆盖层叠在一起。

**设置面板**：游戏内右上角的「设」打开一个居中的弹层，提供同样的音乐 / 音效滑杆、静音，以及「返回标题」（二次确认）；Esc / 遮罩关闭，打开时锁定背景滚动，并把焦点限制在面板内。

声音默认开启，第一次点击后启动，右下角可以静音，偏好会记住。

## 9. 技术实现

- **纯静态**：HTML + CSS + 原生 JavaScript，无构建、无依赖、无后端，`file://` 直接打开即可运行。
- **渲染**：DOM 模板字符串 + 事件委托；每个章节是一个带有 `mount / draw / html / handle` 的对象。
- **状态**：每章一个 `st` 对象，重绘时整块替换，通过 `prev` 值让数值条有过渡动画。
- **3D 场景**：`js/hologram.js` 是一个无依赖的 Canvas 3D 线框渲染器：相机偏航 / 俯仰 / 距离，透视投影，节点辉光与文本标签。每章只声明状态（回合、预测、累计质量），渲染器负责把状态画成可旋转的全息图；`App.set` 在换页时停止上一张画布的 RAF，避免泄漏。
- **存档**：`localStorage`，键名 `darkforest.save.v1`；`file://` 下不可用时自动降级为内存态。
- **调试入口**：`?ch=1..5` 直接进入某章，`?ch=2&auto=1` 自动开始，`?screen=report|finale|codex` 直接查看对应页面，`?demo=1` 生成一份样例报告。
- **可访问性**：按钮为真实 `<button>`，支持键盘 1–5，焦点可见，`aria-live` 播报页面切换，`prefers-reduced-motion` 关闭动画。
- **手册层**：`js/handbook.js` 独立于路由，是一个覆盖层；打开时锁定滚动、Esc 关闭、点击遮罩关闭，不改变当前游戏状态。
- **设置层**：`js/core.js` 里的 `Settings` 覆盖层，同样独立于路由；打开时 `#app.inert`、锁定滚动，关闭后把焦点还给触发按钮。返回标题走 `App.title()`，不会清除已保存的章节进度。
